## Before you start

An order is the family’s payment record. A registration is one child’s place in one session. One order can contain several registrations.

Editing an order, adding a registration or sending a confirmation does not charge a card. Collect any payment separately before recording it as received.

## Find an order and its children

1. Open Registration Orders.
2. Find the family. The Items column shows the children and sessions included.
3. Open the order. Read the Overview, especially Current balance, Payment option, Payment follow-up and any Needs attention message.
4. Open Registrations. The Student registrations section lists the linked registrations.
5. To read an aid request, return to Overview and click Financial aid submission when a linked record is present.
## Review or change a registration

1. Open the order, then Registrations.
2. Check the child, session and current Status.
3. Change Status in the Student registrations list when that is the only change needed.
4. For other changes, click the row’s day or time. Choose Edit, then Edit Record. Clicking the student’s name opens the student profile instead.
5. Save, then check the registration again.
For a Pending child, complete the student-profile review first. Then check the linked registration and set it to Active when the child has been approved and the place is ready. An Active registration does not mean the family has paid the full tuition.

For a Lab, check that this same child has the required Active Players 2, 3 or 4 registration covering the Lab’s dates. Manually adding a row is not a substitute for checking that requirement.

## Record a payment received later

1. Collect or confirm the payment through your usual payment method.
2. Open the family’s Registration Order. Check the existing Current balance.
3. Choose Edit order.
4. Enter the new total still owed in Current balance ($). Do not enter the payment amount.
5. In Reason / payment reference, write what was received and the date. Add a check number or other reference if useful.
6. Save. Allow about a minute, then refresh and check Current balance.
7. If the family needs an updated confirmation, use Send confirmation after the new balance appears.
Example: The current balance is $300. The family pays $100. Enter $200 as the new balance, and a reason such as “$100 check received November 5; check 1234.”

The original checkout payment stays unchanged. Current balance is the amount staff now say is still owed. A later payment in Stripe does not automatically update this field.

## Create an order for a payment made outside the website

1. Make sure the family has a parent account and the child has a Student Profile.
2. Open Registration Orders and choose Create manual order.
3. Select Parent carefully. Use the parent account that owns the child’s profile.
4. Enter Registration total ($): the agreed total for this order. Enter Amount received ($): the money already collected. Enter 0 if nothing has been received.
5. Choose Payment method. Add a Payment reference and Staff notes if useful. Choose No payment required only for an order whose total is $0.
6. Choose Create manual order. Allow about a minute for the details to appear. Correct any Needs attention message before continuing.
7. Open All Session Registrations and choose Add Session Registration.
8. Select Student, Program, Workshop and Session. Choose the correct Status. The form starts at Draft, so change it deliberately.
9. In Registration order (optional), choose the manual order you just created. This list shows that parent’s manual orders, not website checkout orders.
10. Save. Repeat Add Session Registration for each child or session on the same order.
11. Return to the order. Allow about a minute, refresh, and check Items, Registrations, the parent’s email and Current balance.
12. Choose Send confirmation when everything is correct.
Adding registrations does not calculate the agreed total for you or send an email automatically. Enter the correct total before creating the order. If the original total or amount received was entered incorrectly, ask for help rather than changing a balance to hide the mistake.

Do not create a manual order for a website checkout that already has an order. Open the existing order instead.

## Send or resend a confirmation

1. Open the Registration Order. Check the parent, linked registrations and Current balance.
2. Choose Send confirmation.
3. Check the email address shown in the message, then confirm.
4. Allow about a minute. Refresh the order and look at Confirmation status.
Confirmation sent means the email service accepted the message. Ask the family to check spam if needed. A warning such as Delivery needs review should be checked before sending again.

This button sends the registration confirmation, including current recorded details. It does not charge a card, set up payments or resend a Stripe receipt. To resend a payment receipt, use the payment’s receipt controls in Stripe.

## Monthly and later semester payments

1. Check Payment option and the family’s registrations.
2. Contact the parent and agree the amount, dates and payment method.
3. Arrange collection through your usual Stripe or other payment process. The registration website has not scheduled these charges.
4. Use Payment follow-up and Staff notes to keep the team informed.
5. After a payment, update Current balance using the steps above.
Stripe can hold a saved card for a monthly or semester arrangement when checkout collected a card payment. Check that a usable card is present before arranging a later charge. Existing subscriptions may still charge separately; review them before starting another arrangement.
