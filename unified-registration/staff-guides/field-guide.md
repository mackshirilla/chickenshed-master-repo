## The three things to remember

- Order = the family’s payment record. Registration = one child in one session. Student Profile = the child’s details and approval.
- Checkout confirmed does not always mean all tuition has been paid. Always check Current balance.
- Current balance does not include a later semester bill that has not yet been arranged.
## On a Registration Order

Items — The children and sessions included in this order. Open Registrations to see the individual records.

Checkout status — Whether the original website checkout was confirmed, needs review, or was entered by staff. It is not the same as a child’s registration status.

Staff-recorded order — Staff created the order for an arrangement made outside the website. No card was charged by creating it.

Amount paid / Recorded payment — The amount received at the original website checkout, or the amount entered when staff created the order. It does not grow when staff later reduce Current balance.

Current balance — The total still owed on this order according to the latest staff entry. Use Edit order after later payments. Enter the new balance, not the payment amount.

Original remaining balance — If shown, this is the balance immediately after the original checkout. Use Current balance for day-to-day follow-up.

Payment option — Full payment, semester payment or monthly arrangement. In an order containing different types of session, check each registration’s payment details too.

Payment follow-up — A place to track whether later payment arrangements need attention. Updating it does not take money or schedule a charge.

Registration coverage — The session or period the registration covers. It is not a promise that all future semester bills have been paid.

Financial aid submission — Click the linked record to read the family’s submitted aid details. If no aid form was submitted, there may be no link. A manual order does not create an aid application automatically.

Staff reviewed — Use after checking the order. It does not approve a student, collect money or send an email.

Staff notes — Information for the team about the order and arrangements. Do not enter full card numbers or card security codes.

Needs attention — Something needs correcting or checking. Read the message before sending a confirmation.

## When staff create or edit an order

Parent — The account responsible for the order. The linked children must belong to this parent account.

Registration total ($) — The agreed amount for the manual order when it is created. Include any agreed tuition reduction in this total and explain it in notes.

Amount received ($) — The amount already collected when the manual order is created.

Payment method — How that recorded payment was received. Not yet paid means no payment has been recorded. No payment required is for a $0 order.

Payment reference — A check number or other reference that helps find the payment.

Reason / payment reference — Required when staff edit the current balance. Say what changed, the amount received if applicable, and the date.

Registration order (optional) — Links a manually added student registration to that parent’s manual order. It does not create a payment or calculate tuition.

## Registration statuses

Active — The child is enrolled. This does not mean the tuition is fully paid.

Pending — The registration is awaiting review or approval. It does not qualify a child for a Lab.

Draft — An unfinished staff entry. It is not included in the family’s current registration confirmation.

Waitlist — The child is waiting for a place. Paused — The registration is on hold. Trial — A trial registration.

Cancelled — The registration has been cancelled. Archived — An old or removed registration kept for reference. Neither status automatically refunds a payment or changes the order balance.

Deposit Paid — An older status still available in the form. For new orders, check the payment on the order and use Pending or Active to describe the registration itself.

## Confirmation fields

Send confirmation — Sends the family an email listing the linked registrations and the current recorded balance. It works for website and staff-created orders.

Confirmation status — Shows whether the requested email was sent or needs attention. Confirmation sent means it was accepted by the email service; it is not proof the parent opened it.

Last confirmation attempt — When sending was last attempted. A time here does not mean the attempt succeeded; read Confirmation status as well.

## If something looks wrong

- A parent owes money but checkout says confirmed: check Current balance and Payment option. A deposit checkout can be confirmed with tuition still owed.
- A new manual order has no children: add the Session Registrations and select the order on each one.
- A new manual order is missing from the order picker: check the selected child’s parent, wait about a minute, and check the order’s Needs attention message.
- A changed balance or new link is not visible yet: allow about a minute, then refresh.
- A child cannot join a Lab: check that child’s own Active Players 2, 3 or 4 registration and its dates. Approval alone or a sibling’s registration is not enough.
- A receipt is needed: find the actual payment in Stripe. The registration confirmation is a separate email.
If the amount or payment is uncertain, check the original payment before editing the balance or asking the family to pay again.
